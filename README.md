# 词流 · Wordflow

面向真实阅读目标的单用户英语复习 PWA。它把词句收集、系统发音、听辨练习和证据进度放在一个安静的学习流中，用 SQLite 保存每次复习结果。

## 功能

- `认读 / 听辨` 双模式：听辨时先隐藏英文拼写，只播放系统英语发音。
- 词卡内手写巩固：主动选择后用手指书写、对照拼写并记录结果；不自动打断认读，不保存笔迹图片，也不混入阅读证据等级。
- 可靠构词拆解：展示经人工审核的单词、前缀、词根与后缀含义；完整单词片段可查看词库状态并主动加入学习，不按长度机械拆词。
- 美式、英式口音与 `0.65×–1.15×` 语速；可自动播放下一张，并为有证据的词显示 IPA 音标。
- 不设置每日学习上限；长期展示累计复习、已记住数量和真实学习天数。
- TS-FSRS 5.4.2 按逐词表现安排复习；初学1/10分钟、重学10分钟，默认目标保留率90%。旧到期日保留，新调度在后续正式复习时逐词初始化。
- 三按钮明确为没想起来、想起来但慢、记得；主动练习单独记录，不改变正式排程或等级。
- 内置30条教学短句，覆盖动作、否定、条件、因果、比较和指代；工作原句先收藏，核对中文解释后再发布为阅读练习。
- 到期的错词和模糊词优先复测，新收集的工作词优先进入学习，其余新词按课程编号推进。
- 数据库中的最新复习等级与手动修订在同步、重启时保留；升级也保留旧版本中已有的非空内容修订。
- 今日复习、词句库和证据进度三部分；词库支持搜索、筛选、分页、逐条发音和手动增删改。
- `S0–S3` 证据升级，不用累计背词数冒充阅读能力。
- 内置按学习依赖排序的 Reddit 工作英语核心 3000 项，每项有中文核心义；另收录 106 条动词变形、缩写与口语说明，其中 54 条作为额外词卡。现有学习记录和更高证据等级在同步时保留。
- 真实命中收在更多操作，iPhone 专项和旧阅读阶段收在历史档案。新规则正式自评与主动练习分开统计。
- 分类选项共用一份定义，工作词库优先显示，其他分类按需展开。
- 移动端学习页按动态视口和安全区布局，英文、核心释义与评分区同屏；构词、来源和补充说明按需在详情窗口查看，统计留在进度页。
- 原生 PWA 与响应式界面，覆盖窄屏手机和桌面。

发音使用设备内置的 Web Speech API。文本不会上传到第三方语音服务；实际声音取决于当前系统安装的英语语音。

## 本地运行

要求 Node.js 20 或更高版本。

```bash
npm install
npm start
```

打开 `http://127.0.0.1:4317`。

## 数据

- SQLite：`data/wordflow.db`
- 内置种子：`seed/learning-seed.json`
- Reddit 核心词表：`seed/reddit-core-3000.json`（主表 3000 项与补充表 106 条）
- 可选外部档案：通过 `MEMORY_ROOT` 指向包含 `english-vocabulary.md` 等文件的目录
- 导出：进度页右上角下载按钮

## 线上访问

- 地址：`http://YOUR_SERVER_IP/wordflow/`
- 首次使用记账系统的老板账号登录；应用使用 90 天签名 Cookie 保持登录，不保存密码。
- 生产数据：`/var/lib/wordflow/wordflow.db`，每天自动备份并保留 14 天。
- 更新和回滚步骤见 [DEPLOY.md](DEPLOY.md)。

重新生成内置种子：

```bash
npm run sync
```

## 证据规则

- `S0`：出现过，尚未独立答对。
- `S1`：本次能理解；同一天重复答对仍停留在 `S1`。
- `S2`：后续学习日无提示答对。
- `S3`：至少两个不同日期在真实文本中命中。
- “忘了”会缩短间隔，并保守降低已经失效的证据等级。

## 调度与阅读数据

正式复习在一个事务中更新词项、FSRS调度与复习事件。旧事件的评分版本为1，保留原记录；版本2的Hard表示想起但慢，属于正确自评。旧Hard含义不明确，后续兼容请求保守映射为Again，旧事件不回放、不用于拟合参数。

阅读草稿没有中文解释时不会成为正式词句，发布必须填写并核对解释。导出包含词项、事件、调度和草稿。阅读与听辨证据分离、实际时间晋级规则重构仍暂缓，短期步骤不新增延迟记住证据。
